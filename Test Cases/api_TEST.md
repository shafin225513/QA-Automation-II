# API Testing Suite (tests/api/test_product_api.py)
These tests validate the backend directly without using the browser. They ensure the "plumbing" of the application is functional.

## TC-API-01: Create Product (POST)
Objective: Verify the system can create a new record via the REST API.

Logic: 1.  Send a POST request to /posts with a JSON payload (Title, Body, UserID).
2.  Assert the Response Status Code is 201 (Created).
3.  Assert the returned JSON contains the id generated by the server.

### Expected Result: Returning value of status code == 200
### Actual Result: Returned value 200 successfully
